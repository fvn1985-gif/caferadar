Objetivo do Radar de Alocação 2038

O Radar de Alocação 2038 é um sistema de apoio à decisão de alocação patrimonial de longo prazo. Seu objetivo é coletar indicadores de mercado, aplicar regras financeiras previamente homologadas e apresentar uma alocação sugerida para novos aportes e caixa em revisão regular.

O Radar não executa ordens nem movimenta dinheiro. Quando indicadores críticos não podem ser validados, o sistema gera relatório preliminar em vez de inventar dados.

Papel do motor Python como fonte oficial

Todas as decisões calculadas (indicadores, alertas, elegibilidade e alocação) são produzidas exclusivamente pelo motor Python do Radar. O dashboard web apresenta os resultados desse motor, sem duplicar, reinterpretar ou recalcular suas regras financeiras.

Indicadores, alertas, elegibilidade e alocação

  • Indicadores: valores de mercado e métricas técnicas (por exemplo: IBOV, PTAX, Tesouro IPCA+ 2040, DI1, CDS Brasil 5Y, Bitcoin, ERP).
  • Alertas: sinais de atenção derivados dos indicadores (esticamento do IBOV, estresse soberano, ruptura sistêmica).
  • Elegibilidade: definição de quais ativos podem receber alocação, com base em regras de qualidade e atualidade dos dados.
  • Alocação: percentuais sugeridos por ativo, respeitando caps homologados, vetos persistentes e filtros de mercado.

Estes são conceitos gerais. Os valores numéricos, limiares e critérios específicos são definidos e mantidos pelo motor Python e pela documentação de governança do projeto.

Qualidade, atualidade e ausência de dados

O sistema trata explicitamente dados ausentes, inválidos ou desatualizados. Um indicador pode estar em um dos seguintes estados conceituais:

  • Válido: dado disponível, dentro do limite de atualidade e com fonte aprovada.
  • Desatualizado: dado disponível, mas além do prazo de frescura homologado.
  • Inválido / indisponível: dado não disponível, não verificável ou com fonte não autorizada.

Quando dados críticos estão ausentes ou indeterminados, o sistema não preenche lacunas com estimativas. A alocação pode ficar bloqueada até a resolução das pendências.

Escopo do dashboard web

O dashboard web é uma camada de apresentação que consome os resultados do motor Python. Ele não calcula alocação, não aplica regras de elegibilidade e não determina alertas. Apenas exibe, de forma visual, o que o motor já processou.

Esta página de regras é explicativa e não substitui o relatório oficial do sistema (arquivos em output/), os logs de execução nem o banco de histórico local.

Avisos importantes

  • Este é um protótipo visual com dados fictícios.
  • Não é uma recomendação de investimento.
  • Não envia dados para serviços externos.
  • Não realiza operações financeiras.
  • Não substitui a análise do investidor nem o relatório oficial do Radar.
